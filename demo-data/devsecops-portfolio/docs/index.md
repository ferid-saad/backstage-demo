# devsecops-portfolio

Portfolio DevSecOps migré vers Next.js, avec API Express, Docker et pipeline Jenkins.

## Stack technique

- Frontend : Next.js (TypeScript)
- API : Node.js / Express
- Conteneurisation : Docker, Docker Compose
- CI/CD : Jenkins
